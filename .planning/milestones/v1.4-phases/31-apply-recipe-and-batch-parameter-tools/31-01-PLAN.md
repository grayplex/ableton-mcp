**Part A: Create `MCP_Server/devices/convert.py`** (per D-03: conversion on MCP side)

Create a new module with two public functions:

```python
import math
from MCP_Server.devices.catalog import CATALOG

def natural_to_normalized(device_class: str, param_name: str, natural_value: float) -> float:
```

Logic:
1. Look up `CATALOG[device_class]` -- if not found, return `natural_value` unchanged
2. Find param entry where `p["name"] == param_name` -- if not found, return `natural_value` unchanged
3. Get `conv = param_info.get("conversion")`
4. If `conv is None`: clamp to `[param_info["min"], param_info["max"]]` and return (value already in device range)
5. If `conv["type"] == "log"`: clamp to `[natural_min, natural_max]`, return `math.log(clamped / natural_min) / math.log(natural_max / natural_min)`. Defensive: if `natural_min <= 0`, set to `1e-10`.
6. If `conv["type"]` in `("linear", "linear_db")`: clamp to `[natural_min, natural_max]`, return `(clamped - natural_min) / (natural_max - natural_min)`
7. Else: return `natural_value` unchanged

```python
def convert_recipe_to_payload(recipe: dict) -> list:
```

Takes a recipe dict `{device_class: {param_name: natural_value, ...}, ...}` and returns a list of `{"class_name": str, "params": {param_name: normalized_value, ...}}` dicts suitable for the RS `apply_recipe` command payload.

Iterates each `device_class, params` pair, calls `natural_to_normalized` for each param, and builds the payload list.

```python
def get_master_recipe(genre: str) -> Optional[dict]:
    """Get master bus recipe for a genre.

    Args:
        genre: Genre ID or alias.
    Returns:
        Dict of device_class -> param_dict, or None if not found.
    """
    _ensure_initialized()
    norm_genre = _normalize(genre)
    genre_id = _alias_map.get(norm_genre) or _GENRE_ALIASES.get(norm_genre)
    if genre_id is None or genre_id not in _master_registry:
        return None
    return _master_registry[genre_id]
```
