## Milestone Goal

Give Claude production self-awareness — evaluate the current Ableton session across four dimensions (mix balance, arrangement completeness, harmonic coherence, sound selection coverage), return a composite score with letter grade and ranked issues, and offer the top-priority fixes by name.

## Key Accomplishments

1. **Evaluation framework** — `MCP_Server/evaluation/` package with `EvaluationIssue`, `DimensionScore`, `SessionScore` TypedDicts and `grade_from_score()` helper; JSON-serializable, no `.asdict()` needed; grade thresholds A/B/C/D/F at 9/7/5/3 boundaries

2. **Mix balance evaluator** — `evaluate_mix_balance(genre, conn)` diffs current device params vs. role×genre recipe targets using `DIFF_THRESHOLD=0.03`/`CRITICAL_THRESHOLD=0.15`; gain staging deviations from `GAIN_TARGETS` included as additional issues; score = in-range param percentage × 10 − (gain deductions × 0.5)

3. **Arrangement completeness evaluator** — `evaluate_arrangement(conn)` checks every regular track for loaded instrument (critical if missing) and arrangement clips (warning if none); score = weighted clean-track fraction × 10

4. **Sound selection coverage evaluator** — `evaluate_sounds_coverage(conn)` pre-builds role→instrument map from sounds catalog (highest affinity per role tag), matches on `device_name` (display name); mismatched instrument flagged as warning

5. **Harmonic coherence evaluator** — `evaluate_harmonic(conn)` computes in-key pitch class set via pure integer arithmetic from `root_note + cumsum(scale_intervals)`; iterates Session-view clips via `get_session_state` + `get_notes`; no key set → score 10.0 + info issue

6. **`evaluate_session()` MCP tool** — `evaluate_session(ctx, genre)` runs all 4 evaluators via `_run_evaluator` isolation wrapper (per-evaluator try/except fallback), computes composite score as simple average, sorts all issues critical-first, returns up to 3 `top_fixes` each with `tool_call = fix_hint`; registered in `tools/__init__.py`; `MCP_Server.evaluation` added to `pyproject.toml`

## Architecture Decisions

| Decision | Rationale |
|----------|-----------|
| TypedDicts for all schema types | JSON-serializable without .asdict(); consistent with genres/schema.py and PROFILE/RECIPE patterns across codebase |
| genre required for evaluate_session() | Mix balance evaluator cannot compare params without recipe target; no meaningful fallback |
| Simple average composite score | All 4 dimensions equal weight for v1.6; weighted scoring deferred until usage patterns emerge |
| _run_evaluator isolation wrapper | One broken evaluator cannot block entire evaluation; degrades gracefully |
| top_fixes = first 3 severity-sorted issues | Deterministic, predictable; fix_hint authored at issue creation time with full context |
| Pitch classes via integer arithmetic | No music21 dependency for harmonic evaluator; scale_intervals from RS response sufficient |
| Session view clips for harmonic check | Where most MIDI editing happens; arrangement clips require N per-track calls |
