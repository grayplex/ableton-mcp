Build the Phase Execution Plan Engine: a new `get_phase_execution_plan(phase_name, genre, section_name?, context?)` MCP tool that returns a `PhaseChecklist` with concrete, ordered `ExecutionStep` entries — exact tool names and genre-appropriate suggested args.

Claude calls this tool and executes the returned steps in order, eliminating the need for in-context reasoning about "what tool to use next". ## Step 1 — Create `MCP_Server/orchestration/execution.py`

Implement `get_execution_plan(phase_name, genre, section_name=None, context=None)`.

Three-layer architecture (D-02):
1. `_DEFAULT_STEPS[phase_type]` — generic steps used when no genre override exists
2. `_DRUM_PATTERNS[genre_group]` — drum note arrays per genre group (D-04)
3. `_GENRE_PARAMS[genre_id]` — BPM midpoint, scale, instrument hints (D-05)

Genre-to-group mapping for drums:
- house, disco_funk, lo_fi → "house"
- techno, drum_and_bass → "techno"
- hip_hop_trap → "hiphop"
- dubstep → "dubstep"
- trance, synthwave, future_bass → "trance"
- ambient → None (error)

Sentinel descriptions: any step with `"<track_index>"` in suggested_args must have description mentioning "Replace <track_index> with the actual track index from get_all_tracks()".

Section scoping: when section_name is given, replace `create_clip` step with `create_arrangement_midi_clip` using sentinel args `{"track_index": "<track_index>", "start_time": "<section_start_beat>", "length": "<section_length_beats>"}`.

## Step 3 — Add `get_phase_execution_plan` tool to `MCP_Server/tools/orchestration.py`

```python
@mcp.tool()
def get_phase_execution_plan(ctx: Context, phase_name: str, genre: str,
                              section_name: str = None, context: str = None) -> str:
    """Get a concrete ordered execution checklist for a production phase.

    Returns a PhaseChecklist with ExecutionStep entries — exact tool names and
    genre-appropriate suggested args. Steps use sentinel strings (e.g. "<track_index>")
    for session-state values that must be resolved at runtime via get_all_tracks().

    Args:
        phase_name: Phase type slug (setup/drums/bass/harmony/melody/sound_design/arrangement/mix/master)
        genre: Genre id or alias (e.g. "house", "techno", "lo_fi")
        section_name: Optional arrangement section name. When provided, note-writing
                      steps use create_arrangement_midi_clip with sentinel bar positions.
        context: Optional JSON override dict. Keys: instrument, tempo, scale, root_note.

    Returns:
        JSON string with PhaseChecklist or {"error": "..."} on unknown genre/phase.
    """
```
