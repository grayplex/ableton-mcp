# Phase 51 Plan 01: Next-Action Recommender and Phase Transition Gate

## Objective

Implement two final orchestration MCP tools to complete the agent loop:
1. `get_next_actions(genre, phase_name?, n?)` — reads checkpoint, returns next N concrete ExecutionSteps
2. `get_phase_transition_guidance(from_phase, genre?, to_phase?)` — go/no-go verdict before advancing phases

## Context

@51-CONTEXT.md

## Tasks

### Task 1 — Create `MCP_Server/orchestration/next_actions.py`

Type: auto

Create new module with:
- `_phase_complete(phase_type, tracks, clips_by_track, master_devices)` — phase-specific completion heuristics, returns `(is_complete: bool, blockers: list[str])`
- `get_next_actions_result(genre, phase_name, n)` — checkpoint-aware step recommender with graceful fallback
- `get_transition_guidance(from_phase, genre, to_phase)` — live Ableton state check with go/no-go verdict
