<objective>
Implement `get_production_checkpoint(genre?)` MCP tool that reads live Ableton session state
via RS commands and returns a compact `ProductionCheckpoint` identifying which production phases
are done, which is active, and a single-sentence `resume_hint`.

Purpose: Enables context-reset recovery — Claude calls this one tool and knows exactly where to
continue in the production workflow. Phase 50 builds on the TypedDicts from Phase 48 and the
AGENDA_CATALOG phase ordering to infer session progress heuristically from track names, device
presence, and clip presence without requiring explicit bookkeeping.

## Step 1 — Create `MCP_Server/orchestration/checkpoint.py`

New module with `_infer_completed_phases`, `_build_session_stats`, and `get_checkpoint`.

Key heuristics:
- setup: `len(tracks) >= 2`
- drums/bass/harmony/melody: matching track name + has_devices + clips present
- sound_design: any track has AutoFilter/Reverb/etc. device
- arrangement: all instrument tracks have clips
- mix: any track has Compressor2 device
- master (short-circuit): GlueCompressor + Limiter2 on master → all phases complete
