# Milestone v1.5: Sound Selection Intelligence

**Status:** ✅ SHIPPED 2026-03-31
**Phases:** 35-38
**Total Plans:** 6

## Overview

Give Claude instrument-selection taste — map descriptor tags like "warm pad" or "punchy kick" to the right native Ableton instrument and browser category path, eliminating random preset fumbling.

### Phase 37: Descriptor Taxonomy and Scoring Engine

**Goal**: The scoring engine can accept a natural-language descriptor string, tokenize it, score all 6 instruments by summing affinity weights, and return ranked results — and Claude can discover the full descriptor vocabulary
**Depends on**: Phase 36
**Requirements**: PKG-02, SREC-02
**Plans**: 1 plan

Plans:

- [x] 37-01: Scoring engine + list_sound_descriptors MCP tool

**Details:**
- `catalog.recommend(descriptor)` — tokenize (lowercase, strip punctuation, whitespace split), sum role+character affinities, return top match with reasoning
- `catalog.list_descriptors()` — derives vocabulary dynamically from union of all profile affinity keys; always in sync
- `list_sound_descriptors` MCP tool registered in `tools/__init__.py`
- Tie-breaking: (-score, id) alphabetically for determinism; zero-score returns None
- Sample scoring: "warm pad" → wavetable 1.65, "punchy kick" → drum_rack 1.90, "organic" → simpler 0.75
- 62 tests total (+18 new: TestRecommend + TestListDescriptors)

## Milestone Summary

**Key Decisions:**

- Cloned `genres/catalog.py` pkgutil auto-discovery pattern for `sounds/` — zero-registration, one file per instrument
- No schema version/type marker — minimal PROFILE dict constant (like GENRE/RECIPE), add validation later if needed
- Tokenize by lowercase + whitespace split + strip punctuation — simple and predictable
- Weighted sum scoring over role and character affinity axes
- Tie-breaking by (-score, id) alphabetically for determinism
- Zero-score returns None (not an exception) — expected workflow for unrecognized descriptors
- `list_descriptors()` derives vocabulary dynamically from union of all profile affinity keys — always in sync
- Browser path validation deferred (Ableton unavailable) — D-06 fallback applied; "Instruments/[Name]" pattern assumed

**Issues Resolved:**

- `ModuleNotFoundError: No module named 'tiktoken'` in test_genre_quality.py — installed tiktoken as dev dependency (Phase 38)
- `MCP_Server.sounds`, `MCP_Server.genres`, `MCP_Server.mixing` all missing from pyproject.toml — fixed in Phase 38

**Issues Deferred:**

- Browser root path live validation (all 6 instruments assumed per D-06) — deferred until Ableton session available
- Genre-aware recommendations (SREC-04) — post-v1.5
- `test_arrangement.py::test_arrangement_tools_registered` async pytest-asyncio issue — pre-existing, out of scope

**Technical Debt Incurred:**

- All 6 instrument browser root paths are ASSUMED (not live-validated): Wavetable, Analog, Operator, Drift, Simpler use `Instruments/[Name]` pattern; Drum Rack uses `Instruments/Drum Rack` (alternative `"Drums"` unverified)
