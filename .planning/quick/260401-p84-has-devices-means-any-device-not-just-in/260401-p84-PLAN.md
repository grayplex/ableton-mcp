In `_get_arrangement_state` (line 66-72 of scaffold.py), change the track dict construction from:

```python
tracks.append({
    "index": i,
    "name": track.name,
    "has_devices": len(track.devices) > 0,
})
```

to:

```python
tracks.append({
    "index": i,
    "name": track.name,
    "has_instrument": getattr(track, "has_audio_output", False),
})
```

Why `has_audio_output`: This is a standard Ableton Live Object Model property on Track objects. For MIDI tracks, it is `True` only when an instrument device is loaded (instruments produce audio output). For audio tracks, it is always `True` (they inherently output audio). For MIDI tracks with only FX devices, it is `False` — exactly the behavior we need.

Use `getattr` with `False` default as a safety net in case of unexpected track types.

Also update the docstring (line 57) from:
```
tracks: List of {"index": int, "name": str, "has_devices": bool} dicts.
```
to:
```
tracks: List of {"index": int, "name": str, "has_instrument": bool} dicts.
```
