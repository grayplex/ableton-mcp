    - Test: Genre parameter passed through to get_section_state calls

  <action>
    1. Add `compare_sections` function in `MCP_Server/tools/refinement.py` after the existing `get_section_state` tool (around line 271). Register with `@mcp.tool()`.

    Signature:
    ```python
    @mcp.tool()
    def compare_sections(ctx: Context, section_a: str, section_b: str, genre: str = None) -> str:
    ```

    2. Implementation approach — call `get_section_state` as a plain function (it is a regular Python function decorated with @mcp.tool, so direct calls work). Parse the JSON results into dicts.

    3. If either section has an error, return early with:
    ```python
    {"section_a": section_a, "section_b": section_b, "error": "...", "diff": None}
    ```

    4. Build the diff structure:
    ```python
    {
        "section_a": section_a,
        "section_b": section_b,
        "bar_ranges": {
            "section_a": {"start": N, "end": N},
            "section_b": {"start": N, "end": N},
        },
        "only_in_a": [track_name, ...],   # tracks present in A but not B
        "only_in_b": [track_name, ...],   # tracks present in B but not A
        "track_diffs": [
            {
                "track_name": str,
                "role": str | None,
                "clips": {"a": int, "b": int},
                "total_notes": {"a": int, "b": int},
                "avg_rhythm_density": {"a": float|None, "b": float|None},
                "pitch_range": {
                    "a": {"min": int|None, "max": int|None},
                    "b": {"min": int|None, "max": int|None},
                },
                "mix": {
                    "volume": {"a": float|None, "b": float|None},
                    "pan": {"a": float|None, "b": float|None},
                },
                "devices_a_only": [str, ...],
                "devices_b_only": [str, ...],
                "devices_both": [str, ...],
            },
            ...
        ],
        "error": None,
    }
    ```

    5. Match tracks between sections by `track_name` (exact match). For each matched track, compute:
       - `clips`: count of clips in each section
       - `total_notes`: sum of note_count across clips (treat None as 0 for audio clips)
       - `avg_rhythm_density`: average rhythm_density across MIDI clips (skip None values)
       - `pitch_range`: overall min/max across all clips
       - `mix.volume`, `mix.pan`: from mix_context
       - `devices_a_only`, `devices_b_only`, `devices_both`: compare device class_names from mix_context.devices

    6. Write tests in `tests/test_compare_sections.py` following the same mock pattern as `tests/test_refinement_application.py`:
       - Mock `MCP_Server.tools.refinement.get_ableton_connection` to return a mock conn
       - The mock conn.send_command should return canned arrangement state, clips, notes, mix_state
       - OR more simply: mock `get_section_state` directly (since compare_sections calls it as a function) to return pre-built SectionState JSON strings
       - Import compare_sections from MCP_Server.tools.refinement
       - Use the same mcp/sys.modules mocking boilerplate from test_refinement_application.py
  </action>
