## What Was Done

### Task 1: Add TTL cache to get_checkpoint and expose invalidation
**Commit:** 039793c

Added a 30-second TTL cache to `get_checkpoint()` keyed by genre:

- Module-level `_checkpoint_cache` dict stores `{"result": dict, "ts": float}` entries
- Cache check at top of `get_checkpoint` returns cached result if within TTL
- Three return paths handled: error (NOT cached), empty session (cached), normal (cached)
- `invalidate_checkpoint_cache(genre)` clears a specific genre or all entries
- Exported via `MCP_Server/orchestration/__init__.py`

Tests added (4 new in TestCheckpointCache):
- `test_second_call_uses_cache` -- zero additional send_command calls on second invocation
- `test_different_genre_not_cached` -- independent cache entries per genre
- `test_invalidate_forces_refresh` -- cache invalidation forces fresh Ableton query
- `test_error_not_cached` -- connection errors bypass cache

Also added `setup_method` to existing TestCheckpoint class to clear cache between tests.
