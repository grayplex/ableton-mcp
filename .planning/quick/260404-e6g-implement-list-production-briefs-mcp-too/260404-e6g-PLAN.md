    - interpret_prompt calls record_brief with source="interpret_prompt" after successful derive
    - interpret_prompt_to_plan calls record_brief with source="interpret_prompt_to_plan" after successful derive
    - Neither tool records a brief on error (exception path)
    - list_production_briefs returns JSON with count, session_started, and briefs array
    - Each brief summary in array: index, raw_prompt, primary_genre, bpm_range (string like "125-135"), key_feel, energy_level, confidence, source, timestamp

  <action>
    1. Create `MCP_Server/prompt/history.py` following the exact pattern from `MCP_Server/refinement/history.py`:
       - Module-level `_BRIEF_LOG: list = []` and `_SESSION_START: float` initialized to `time.time()`
       - `record_brief(raw_prompt: str, brief: dict, source: str) -> None` — appends `{"raw_prompt": raw_prompt, "brief": brief, "source": source, "timestamp": time.time()}` to `_BRIEF_LOG`
       - `get_briefs() -> list` — returns `list(_BRIEF_LOG)` (shallow copy)
       - `clear_briefs() -> None` — calls `_BRIEF_LOG.clear()`

       - Add import: `from MCP_Server.prompt.history import record_brief, get_briefs, _SESSION_START`
       - In `interpret_prompt`: after `brief = derive(text)`, before return, add `record_brief(text, brief, "interpret_prompt")`
       - In `interpret_prompt_to_plan`: after `brief = derive(text)`, before the genre resolution block, add `record_brief(text, brief, "interpret_prompt_to_plan")`
       - Add new tool function `list_production_briefs(ctx: Context) -> str`:
         - Docstring: "List all production briefs interpreted during this session. Returns a JSON summary of each prompt interpretation, ordered chronologically. Use after a context reset to recall what prompts have been processed."
         - Call `get_briefs()` to get entries
         - Build summaries: for each entry at index i, extract from `entry["brief"]`: `primary_genre`, `tempo_range` (format as `"{min_bpm}-{max_bpm}"`), `key_feel` (format as `"{scale} {mode}"`), `energy_level`, `confidence`. Include `entry["raw_prompt"]`, `entry["source"]`, `entry["timestamp"]`, and `i` as index.
         - Return `json.dumps({"count": len(entries), "session_started": _SESSION_START, "briefs": summaries}, indent=2)`
