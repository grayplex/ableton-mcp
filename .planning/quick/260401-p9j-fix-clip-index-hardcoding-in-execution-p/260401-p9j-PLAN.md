<objective>
Replace all hardcoded `"clip_index": 0` values in session-clip execution steps with a sentinel value (`"<clip_index>"`) and an instruction telling Claude to resolve it at runtime by querying `get_track_info()` for the first empty clip slot.

Purpose: Prevents silent failures when slot 0 is already occupied (e.g., after multiple production rounds in the same session).
Output: Updated execution.py with sentinel clip_index, updated tests.
</objective>

<!-- Existing sentinel pattern in execution.py -->
From MCP_Server/orchestration/execution.py:
```python
_SENTINEL_NOTE = "<track_index>: resolve via get_all_tracks()"
```

The clip_index sentinel should follow the same pattern. The Remote Script's `get_track_info` returns:
```json
{
  "clip_slots": [
    {"index": 0, "has_clip": true, "clip": {...}},
    {"index": 1, "has_clip": false, "clip": null}
  ]
}
```
So the sentinel instruction should say: "resolve via get_track_info() -- use first slot where has_clip=false".
</interfaces>
